# Knight — 无名钟楼序章 2026.09.08-r1

这是历史开发试玩候选的筛选源码归档，不是最终美术验收版、正式发行版或免安装 EXE。
修复普通启动与录像地图不一致的问题，保留五个连续扇区、15 个微场景和 11 条路段；调整 Boss 血条、开门显示、教学卡避让、能量/热量反馈及第三上升抓点。

## 启动

需要 Godot 4.7.1 Mono（.NET 版）和 .NET SDK 9.x；普通 Godot 非 .NET 版不能运行此 C# 工程。
打开本地 PowerShell，进入解压后的工程目录，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\play-prologue.ps1 -GodotPath "你的Godot Mono可执行文件路径" -DotnetRoot "你的.NET SDK目录"
```

`Play-Knight.cmd` 使用开发机的默认安装目录；其他电脑请用上述显式路径命令。
启动器先检查地图、编译和导入，再启动游戏。退出后的试玩报告仅保存在本机，不自动上传。

## 操作

- A/D：移动；Space：普通跳跃；Shift：冲刺。
- Q：攻击模式；E：机械爪模式；鼠标瞄准，左键执行当前模式。
- 抓附后按住左键维持连接；W/S 收放绳；Space 一次助推；松开左键脱离。
- 右键防御；攻击、防御消耗能量，护盾会过热。
- 1–4：快捷槽；Esc：暂停和查看操作。

## 已知边界

程序化地形、角色/敌人和 UI 是可替换的美术基础，整体美感及首次上手难度未完成真人验收。
原版本仍有机械爪释放后上升惯性可能被短跳逻辑截断的问题；修复开发中的 r3 未包含在本包。
历史固定帧自动路线/录像不是正常速度帧率证明，也不是人类通关证明。先前偶发的上升段失败原因未完全确定。
本次归档不是新玩法提升；正常速度手感、独立完整认证和正式美术仍待继续。
