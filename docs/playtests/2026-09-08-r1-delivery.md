## Changes

- Rebuilt and retained the five continuous sectors and main scene: 15 micro-scenes,
  11 traversal segments and terrain grapple profiles. The ordinary launcher checks
  these on-disk scenes before building. Older capture wrappers restored sparse HEAD
  scenes, so a successful old capture was not proof of the normal delivered map.
- Moved the Boss HUD above the combat area. Bound both generated door panels to the
  same open/closed state as their collision, including defeat and retry.
- Added cached teal energy, amber heat and orange-red overheat styles; kept the
  underlying energy/shield rules and layout unchanged.
- Hid launch/landing debug polygons without deleting their test contracts. Added
  static, low-contrast silhouettes and distinct landmarks to all five backgrounds.
- Moved the third ascent anchor down from local Y=500 to Y=580. The input proof now
  waits for a real on-screen target with a 32-pixel inset during the ordinary jump,
  instead of injecting an off-screen mouse coordinate.
- Hidden gameplay reticle during recovery and completion; restored it on return.
- Corrected guidance protection to use mounted continuous-sector and player roots,
  not null legacy `CurrentRoom/Art`. Protected the live tether, returning shuttle,
  dedicated anchors and animated hammer; excluded large grippable static terrain
  from the prompt exclusion area. Used Label's actual shaped minimum height for
  wrapped Chinese/fallback fonts and theme line spacing.
- Added `Play-Knight.cmd`, `VERSION.txt` and an outer workspace launcher. No paid
  generation, new remote services or separately purchased assets were used.
