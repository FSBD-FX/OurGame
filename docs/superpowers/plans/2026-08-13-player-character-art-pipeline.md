# Player Character Art Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the approved Thread-Spool Bearer identity, prove six runtime clips covering the first five animation families, and replace the prototype player drawing with a manifest-driven layered Godot presentation without changing gameplay rules.

**Architecture:** Codex's host-native image tool supplies the original identity, constrained edits, and one multi-row grid per action without an external image API key or separate pay-per-call invoice. Agent Sprite Forge performs deterministic chroma cleanup, frame splitting, grounded scale/feet locking, QC, and transparent exports; `sprite-gen` performs human curation, atlas composition, and manifest generation, and project-owned C# imports that manifest into `SpriteFrames`. A `PlayerAnimationCoordinator` observes existing motor, combat, thread, health, and facing state, while a separate lantern spring visual follows the body and never owns collision, damage, cooldown, or targeting.

**Tech Stack:** Godot 4.7.1 Mono, C#/.NET 9, PowerShell, Codex host-native image generation/editing, Agent Sprite Forge `generate2dsprite`, `sprite-gen`, Gorest, Pillow, Git.

## Why Generation Is Still Needed Without a Paid API

Agent Sprite Forge and `sprite-gen` are production pipelines rather than offline painting models. They can plan the grid, remove the chroma background, split and align frames, reject defects, curate poses, assemble an atlas, and write metadata, but they still require original pixels. Codex's host-native image tool supplies those pixels using the current product's included image allowance; local tools perform every deterministic step afterward.

| Gate | Host-native work | Local work | Quota policy | Accepted result |
| --- | --- | --- | --- | --- |
| A | One identity candidate at a time | 96 px review and archival | One attempt, then user review; a rejection authorizes no automatic reroll | One user-approved full-composition identity reference |
| B | One body-only edit; lantern-only edit only when component extraction fails | Cutout, component extraction, normalization, alpha QC | Log each edit attempt; no external API charge | Identity-locked body anchor and isolated lantern source |
| C | One multi-row grid per clip | Agent Sprite Forge processing/QC, `sprite-gen` curation and packing | Six first attempts; regenerate only a specifically failed action after review | Six accepted action grids and one runtime atlas |

The first pass therefore creates no separate image API bill. It does consume host image quota, including rejected attempts. Model-host synthesis creates the novel art; all cleanup, extraction, QC, curation, atlas packing, manifest generation, Godot import, runtime animation, and verification are local.

```csharp
using Knight.Presentation;

namespace Knight.Tests.Unit;

public static class PlayerArtManifestTests
{
    public static void Run()
    {
        ParsesAbsoluteFrameRectangles();
        RejectsMismatchedFrameCounts();
        RejectsOutOfBoundsRectangles();
        RejectsMissingAnimationMetadata();
        RejectsNonPositiveFps();
    }

    private static void ParsesAbsoluteFrameRectangles()
    {
        PlayerArtManifest manifest = PlayerArtManifestParser.Parse(ValidJson(), "res://assets/player/test.png");
        TestAssert.Equal("thread-spool-bearer", manifest.CharacterId, "character id is preserved");
        TestAssert.Equal(2, manifest.Clips["idle"].Frames.Count, "idle uses manifest rectangles");
        TestAssert.Equal(new PlayerAtlasRect(256, 0, 256, 256), manifest.Clips["idle"].Frames[1],
            "second idle rectangle remains absolute");
        TestAssert.True(manifest.Clips["idle"].Loop, "idle loop flag is preserved");
        TestAssert.True(!manifest.Clips["jump"].Loop, "jump one-shot flag is preserved");
    }

    private static string ValidJson() => """
    {
      "characterId":"thread-spool-bearer",
      "game_input":"player-atlas.png",
      "animation":{"rows":{
        "idle":{"frames":2,"fps":6,"loop":true},
        "jump":{"frames":1,"fps":10,"loop":false}
      }},
      "frame_layout":{"sheetWidth":512,"sheetHeight":512,"rows":{
        "idle":[{"x":0,"y":0,"w":256,"h":256},{"x":256,"y":0,"w":256,"h":256}],
        "jump":[{"x":0,"y":256,"w":256,"h":256}]
      }}
    }
    """;

    private static void RejectsMismatchedFrameCounts() => ExpectInvalid(
        ValidJson().Replace("\"frames\":2", "\"frames\":3"), "idle");

    private static void RejectsOutOfBoundsRectangles() => ExpectInvalid(
        ValidJson().Replace("\"x\":256,\"y\":0", "\"x\":400,\"y\":0"), "idle");

    private static void RejectsMissingAnimationMetadata() => ExpectInvalid(
        ValidJson().Replace(",\n        \"jump\":{\"frames\":1,\"fps\":10,\"loop\":false}", ""), "jump");

    private static void RejectsNonPositiveFps() => ExpectInvalid(
        ValidJson().Replace("\"fps\":6", "\"fps\":0"), "idle");

    private static void ExpectInvalid(string json, string clip)
    {
        try
        {
            PlayerArtManifestParser.Parse(json, "res://assets/player/test.png");
            throw new InvalidOperationException("expected manifest rejection");
        }
        catch (InvalidDataException exception)
        {
            TestAssert.True(exception.Message.Contains(clip), "rejection names the invalid clip");
        }
    }
}
```

```python
from collections import deque
from pathlib import Path
from PIL import Image

source = Path(r"E:\OurGame\ArtProduction\thread-spool-bearer-v1\layers\full-rgba.png")
output = source.with_name("lantern-rgba.png")
image = Image.open(source).convert("RGBA")
width, height = image.size
alpha = image.getchannel("A")
unvisited = {(x, y) for y in range(height) for x in range(width) if alpha.getpixel((x, y)) >= 16}
components = []
while unvisited:
    start = unvisited.pop()
    queue = deque([start])
    points = [start]
    while queue:
        x, y = queue.popleft()
        for neighbour in ((x - 1, y), (x + 1, y), (x, y - 1), (x, y + 1)):
            if neighbour in unvisited:
                unvisited.remove(neighbour)
                queue.append(neighbour)
                points.append(neighbour)
    components.append(points)
if len(components) < 2:
    raise SystemExit("LANTERN_EXTRACTION_BLOCKED: foreground is connected")
body = max(components, key=len)
body_top = min(y for _, y in body)
candidates = [c for c in components if len(c) >= 64 and max(y for _, y in c) < body_top]
if len(candidates) != 1:
    raise SystemExit(f"LANTERN_EXTRACTION_BLOCKED: expected one detached upper component, found {len(candidates)}")
lantern = candidates[0]
left = max(0, min(x for x, _ in lantern) - 2)
top = max(0, min(y for _, y in lantern) - 2)
right = min(width, max(x for x, _ in lantern) + 3)
bottom = min(height, max(y for _, y in lantern) + 3)
image.crop((left, top, right, bottom)).save(output)
print(f"LANTERN_EXTRACTION_OK {output}")
```

```csharp
public partial class ImportPlayerArt : SceneTree
{
    private const string ManifestPath = "res://assets/player/thread-spool-bearer/player-atlas.json";
    private const string TexturePath = "res://assets/player/thread-spool-bearer/player-atlas.png";
    private const string OutputPath = "res://assets/player/thread-spool-bearer/player-animations.tres";

    public override void _Initialize()
    {
        PlayerArtManifest manifest = PlayerArtManifestParser.Parse(
            FileAccess.GetFileAsString(ManifestPath), TexturePath);
        Texture2D texture = ResourceLoader.Load<Texture2D>(TexturePath);
        var frames = new SpriteFrames();
        frames.RemoveAnimation("default");
        foreach ((string name, PlayerAnimationClip clip) in manifest.Clips)
        {
            frames.AddAnimation(name);
            frames.SetAnimationSpeed(name, clip.Fps);
            frames.SetAnimationLoop(name, clip.Loop);
            foreach (PlayerAtlasRect rect in clip.Frames)
            {
                frames.AddFrame(name, new AtlasTexture
                {
                    Atlas = texture,
                    Region = new Rect2(rect.X, rect.Y, rect.Width, rect.Height)
                });
            }
        }
        Error result = ResourceSaver.Save(frames, OutputPath);
        GD.Print($"PLAYER_ART_IMPORT_OK animations={manifest.Clips.Count} result={result}");
        Quit(result == Error.Ok ? 0 : 1);
    }
}
```
