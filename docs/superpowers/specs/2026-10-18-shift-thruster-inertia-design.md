## 1. 意图、事实与取舍

用户要的是一次短喷带来加速与位移，停喷仍有余速，反向操作能有效刹车；整体加减速、重力与落地反馈更接近力学。未来推进器可拾取和更换。保持纯键盘，Shift替代现有冲刺，不额外叠第二种机动按键。

当前Shift直接覆盖速度为620px/s、持续0.14s，活动帧绕过普通重力；空中松键减速2800反而大于反向输入加速1500。现有抓爪动量标志还影响气流和相机，摔伤按落差而非撞击速度。简单把DashSpeed换成加速度或给旧冲刺加喷焰，不能满足新需求。

选择“现有CharacterBody2D＋单一Motor＋有限推力／阻力／制动”。它保留原生碰撞、可控角色与抓爪接入口，推进器提供参数和运动状态，不另起一个写位置的控制器。替代方案“一次速度冲量＋拖尾”较小但仍缺少喷射加速过程；直接换RigidBody2D会扩大至站地、平台、抓爪、相机及全部路线重构，本次不采用。

本版追求力学反馈一致，而不是严格现实仿真。保留土狼时间、跳跃缓存、空中次数、终端速度及安全落差等明确游戏性辅助。首次不同时改地图尺度、全局重力数值、普通跳跃高度、敌人参数或原生碰撞形状；不能宣称已标定地球重力／质量。像素单位也不能直接套9.81而不换算尺度。

## 3. 操作与能力预算

- Shift按下边缘接受一次固定时长短喷；长按不延长，不自动连发。燃烧中新的Shift按下拒绝、不排队，结束后不重放旧输入。
- 接受时使用现有键盘八向解析结果并锁定喷射方向，方向归一化；此后改变方向键不转动本次喷嘴向量。无方向沿现有稳定朝向／方向解析，首次默认向右；不用鼠标改目标。
- 首版主动反向刹车明确为**水平A/D**。W/S继续参与八向喷射方向与攻击／机械爪瞄准，不新增按住W升空或S持续下降的控制。竖直运动由一次合法上／下短喷、重力、风和真实抓爪力共同决定，不宣传A/D可抵消竖直重力。
- 保留现有一次空中使用预算及真实落地恢复。接受资格使用本tick开始、动作提交前的真实floor状态；“同帧跳跃”使用仲裁前原始Space按下边缘，不使用已被Shift吞掉的JumpPressed。已在空中起喷，或地面起喷且同帧有原始Space边缘，均消耗空中资格；地面单独起喷不额外消耗。地面起喷向上离地后的一次空中喷射是明示的原预算组合，不是普通二段跳。
- 抓爪、顶撞、墙碰、反弹、空中换区、暂停／恢复和喷射结束均不补空中资格。被墙挡住的喷射也不退款；重复按键不能蓄力或恢复次数。
- 本版沿用原Dash“不额外耗能、不积热、没有专属无敌”的资源规则；不把推进器燃料自动等同盾的气力／过热条。未来若增加消耗，另做战斗资源平衡。
- 原J/K/L/Q及1–4操作不改变。原动作仲裁仍适用；L按住时不接受新Shift，包括原先盾过热但L仍按住的边界，不顺带修成另一套输入规则。暂停、死亡和新局继续清理过期单次输入。
- 同帧Shift＋Space且Shift被接受时，沿原Shift优先级只开始短喷，普通跳边缘被消费、不缓存到喷后重放；按上一条预算规则消耗空中资格。拒绝的Shift也不排队或补次数，不能靠组合键产生额外普通跳跃。
- 接受是一个事务：先只读检查存活／暂停、输入仲裁、现有燃烧、预算及配置，然后一次提交预算消费、撤销旧爪cast／修正、继承速度和起喷事件。被拒绝的Shift不得撤爪、改来源或覆盖速度；只拒绝这次请求，原来合法的重力、制动、燃烧或爪过程仍继续，不提前返回跳过整帧物理。

### 4.1 推力、重力和速度上限

接管喷射前先继承实际身体速度，不把起始速度设成固定值。每步只对剩余燃烧时间与delta的较小值积分喷力，最后不足一帧的燃烧不能额外喷满一个tick。非站地时，喷射全过程仍受现有重力及终端下降规则；不再因为IsDashing而提前返回跳过重力。同帧普通跳沿第3节的消费规则，不把Shift当成JumpPressed。

沿锁定方向d可增加的速度为`min(ThrustAcceleration × 有效燃烧时长, max(0, PoweredProjectionLimit − v·d))`。这只限制本次喷力新增的平行分量：不在启动时把已有抓爪／平台余速压到850，不把垂直重力或切向速度一起归一化。碰撞仍由真实MoveAndSlide消除受阻分量；不可通过直接改位置、穿墙或关闭碰撞完成位移。

Motor保留唯一最终速度／碰撞权威，每个真实physics step只执行一次MoveAndSlide。确定的顺序如下；拆分燃烧／非燃烧积分段不增加原生移动调用：

1. 取真实floor、原始输入和当前已碰撞回写的速度；按第3节原子仲裁。有效接管只继承一次，拒绝请求不跳过后续积分。
2. 将本tick分成剩余燃烧段及其后的非燃烧段。后续A/D与喷嘴水平分量相反而取消时，本tick直接走非燃烧段。各段使用同一帧初floor判定，真实碰撞后才更新floor；不猜测中途已经站地。
3. 每段先做水平控制。非零水平喷嘴的燃烧段不叠普通跑动／普通反向制动，仅施加一次被动地面摩擦或空中横向阻力；反向喷嘴跨零后仍由同一喷力加速。纯竖直喷嘴的水平轴，以及所有非燃烧段，使用4.2的互斥普通控制分支；同一段不再叠第二份摩擦／阻力。
4. 未真实附爪时积分该段重力，然后计算喷力。投影公式中的v明确为本段水平控制与重力之后、喷力和风之前的速度。随后执行原下降终速限制；向下短喷不能绕过780的现有下降上限。因此向下喷在已达终速时不会额外加速，这属于首版保留的游戏性限制。
5. 本tick各段结束后，未附爪时按原风区合同合成一次整tick风量，不因燃烧／余速标签豁免；真实爪接管时沿原爪单一速度所有权，不另积分一套自由重力／风。风后的下降限速沿原风区合同，不复制第二份裁剪规则。保存接触测量输入，再唯一一次MoveAndSlide，按实际碰撞回写速度、落地和来源状态。

该顺序是离散积分合同，不把有限tick的位移声称为解析连续轨迹。30／60／120Hz须检查收敛；燃烧最后一小段不能因tick差异多发推力。

### 4.2 余速与主动制动

燃烧结束只停止推力，不清零实际速度。无输入时地面按有限摩擦减速，空中横速按`exp(-AirDragRate × delta)`衰减，不用每帧固定乘数。接近零允许小于1px/s的数值停稳阈值，该阈值不承担高速刹车。

非燃烧水平轴采用互斥分支：无输入时只用被动摩擦／阻力；同向输入且横速已超过跑速时，不主动追260强刹，也不继续叠加普通跑动加速度，仅由被动阻力逐步回落。低于跑速时按原普通加速度驱动，不再同时叠一份被动阻力。零速有输入按普通驱动起步；这些分支不得重复执行。同向不能无限加速，也不能凭按住方向在超跑速阶段抵消全部阻力。

反向A/D与实际横速异号时，用有限反向制动力先刹至零，剩余步长才按普通反向加速度起步；不能直接翻转速度，也不能把强制动力继续当作反向跑动加速度。燃烧中仲裁必须区分以下三种情况，不能将接受时的反向喷射误判为取消：

- A/D相对锁定喷嘴的水平分量反向：立即终止本次全部剩余喷力，再按实际横速制动或普通驱动，不退款、不恢复资格、不转动喷嘴；已经产生的竖直／切向余速不直接归零。
- 新喷嘴本来就朝现有横速的反方向，且A/D与该喷嘴同向：这是合法反向短喷，以喷力本身有限减速，不再叠第二份普通反向制动力，不能因为起始速度仍朝旧方向就立刻取消。
- 喷嘴为纯竖直方向：反向A/D只对水平分量施加制动，不取消独立竖直喷力。W/S仍不构成持续垂直刹车／悬停控制。

这样既避免“反向仍被同向喷力继续加速”，也保留向当前运动反方向喷射的合法用途。接受方向、实际速度和后续制动输入必须分别记录，不能用同一个direction字段替代三者。

### 4.3 独立上升余速保护

区分燃烧期、喷后观察标签、上升来源保护与抓爪环境授权。只有本次向上喷力真实增加上升分量才建立推进器上升保护，不以`Velocity.Y < 0`泛指普通跳、气流或爪。仍有效的抓爪释放上升保护保留其原来源：水平Shift不撤它，也不将它冒认成推进器来源；从实际附着爪接管时，若原交接合同赋予上升保护，同样单独传递该来源。

上升来源保护只阻止普通JumpCut截断对应来源的余速，不额外施力，也不提供风／相机／摔伤权限。燃烧结束或表现标签到时，不删除仍有效的上升保护；真实上升结束、顶撞、落地、普通新跳重新接管、外部完整速度替换、死亡／重置及抓爪实际接管时清除对应旧来源。旧PreservingGrappleReleaseMomentum不能继续同时代表这些权限；需拆开迁移，不能简单清一个布尔值连带切掉vy。

| 下劈反弹／ExternalImpulse | 保持该接口“完整替换速度”的原语义，结束燃烧及相关上升保护，不补次数；推进器自己不能逐帧调用它加力 |

| 暂停 | 物理与燃烧计时冻结；恢复后只继续暂停前剩余有限过程，不重放旧Shift，不补资格，也不按墙钟时间耗掉喷射 |
| 死亡／复活／新局 | 清燃烧、owned效果、上升来源和旧回调；按原明确恢复合同重置运动及允许的生命／次数，不进行合同之外的回血、补次数或重复恢复来掩盖失败 |
| 单纯换区／出屏 | 同一Player仍连续运动，不因sector卸载重挂补资格或重置余速；旧环境授权正确撤销 |

原IsDashing与计数API可暂留兼容别名，但IsDashing只代表真实燃烧期，不包括长时间余速／制动。新typed观察数据区分Burning、Coasting、Braking及真实开始／结束／取消原因。接受事务生成单调BurnId并绑定角色生命周期及配置epoch；拒绝不生成成功身份。燃烧结束只发一次终止事件，ID可用于后续短观察，不能恢复已结束的燃烧；新cast取代观察身份，旧回调仍永久无权修改新状态。

Coasting是实际发生过非零喷力后的短观察／表现标签，不是精确的“速度有多少来自推进器”测量，也不拥有第二套速度。停喷后最长0.45秒（只属表现配置）；普通新跳、真实接爪、完整速度替换、真实落地、已推进分量被碰撞全部阻断、主动水平刹至零、死亡／重置或新cast取代时提前退出。取消余喷不自动删除已产生的余速。Braking根据真实水平制动是否在执行单独观察，可与短余速观察同时成立；没有旧喷射时的普通刹车不得假称有推进器BurnId。观察退出不改速度、次数或仍有效的上升保护；普通跳／风不能创建或延长它。

表现、旧Thread、风、爪、摔伤和相机消费者逐项迁移，不能因旧名字继续保留“无重力速度覆盖”的分支。

## 6. 着陆冲击：兼容旧地图的减伤方案

这是**本轮随书面规格获批、尚未实施的新增规则**。不能同时允许真实减速又承诺旧纯落差规则已符合低速着陆直觉；也不能直接改成只按撞地速度，因为当前780终端速度会让不同高度难以区分。

选择保留高度伤害基数，再由真实着陆冲击决定减免。这是兼容型游戏规则，不是严格的现实组织／材料损伤模型；原600px安全落差仍保留，低落差不会因为这一版新算法被额外加伤。

1. 高度基数`Dheight = ceil(max(0, height − 600) / 400)`，沿用连续下降最高点记录。基数不要先按当前血量截断。
2. 首版仅满足下述唯一floor可靠采样条件时，取接触之前身体实际世界接近速度vbefore（平台携带只计一次）、法线和接触点collider速度，计算`vimpact = max(0, −(vbefore − vcollider)·normal)`；多个／混合支撑或任一测量不可靠均回退旧高度结算，全软豁免另按原合同处理。不能用碰撞后已归零的Y速度，不能只看技能状态。采样边界见下文。
3. 初始安全冲击速度300px/s，参考冲击速度780px/s。`factor = clamp((vimpact − 300)/(780 − 300), 0, 1)²`；`D = ceil(Dheight × factor)`，最后再应用原最大伤害限制／Health接收规则。
4. 所有真实有效支撑均显式bool-true的soft_landing时仍免伤；缺失、非bool或false均按普通支撑。任何普通支撑存在就不走全软豁免，不能靠一角碰软垫屏蔽普通地面。
5. 满足首版可靠采样条件时，高速正常落地接近780保留旧高度伤害，实际慢速落地不高于300减至0。仅按Shift但落地仍高速不减伤；喷后加速重新落下同样按可靠撞击或回退规则计算，没有永久免伤标志。
6. 原真实爪刹车／上升、反弹和传送起点规则保留，不给推进器按键新增ResetOrigin捷径。每次实际落地只结算一次，Health原无敌拒绝时不在站稳后补扣。
7. 熔炉／KillZone即死、战斗伤害、激光／齿轮等独立危险不走此减免，不因低速碰触就安全。

600／400读取原角色FallSafeHeight／FallHeightPerDamage，参考冲击速度读取当前角色MaxFallSpeed，本版默认780；安全冲击速度是独立角色落地配置，不属于可更换喷嘴。必须校验这些配置有限、参考速度大于安全速度，禁止在各消费者复制另一份常量。无有效floor测量、非法法线或非有限速度时不启用冲击减免，退回原高度结算并记录明确诊断；不能把缺失／NaN样本当成0速安全落地。

采样采用保守的公开API适配，不修改引擎或改用多次MoveAndCollide。已核对当前引擎提交[a13da4feb的CharacterBody2D实现](https://github.com/godotengine/godot/blob/a13da4feb/scene/2d/physics/character_body_2d.cpp#L40)：平台携带可在普通slide前单独移动；real_velocity是整步位移平均；连续slide会改变后续运动。这三者不能当成每次接触的pre-impact速度。

首版仅对“从空中开始、无平台携带步骤、本步唯一实际slide接触即有效floor、非恢复／嵌入解算且无额外snap”的可辨识落地启用冲击减免；此时使用已保存的碰撞前指令世界速度与该floor接触点速度。需要验证travel／remainder与本步指令运动一致，并使用公开API的重叠深度等证据排除恢复推挤；公开API没有每次slide的入射速度或独立平台携带来源标志，不能虚构这些字段。任何来源无法排除就回退，不从已有collision结果猜一个“安全”值。移动floor本身不被排除，但若不能可靠取得接触点速度就回退。连续墙→地、混合／多个支撑、平台携带、纯snap或恢复接触等复杂情形**首版保留旧高度结算，不宣称已得到精确相对冲击**；全软免伤独立沿原合同保留。适配器必须报告测量有效性与回退原因，不能猜测或重加／重减平台速度。

这是明确的首版能力边界：复杂接触即使看似慢速也可能仍按旧落差受伤；不能通过删碰撞或忽略普通支撑得到减伤。若要让所有复杂接触也具有可靠冲击减伤，需独立验证更完整的接触采样方案，不能以此书面公式冒认完成。

满足首版可靠采样条件时，校准对照必须包含：800px落差、780px/s撞击仍1伤；相同落差降至不高于300为0；1400px落差、540px/s法向撞击时高度基数2、factor0.25、向上取整为1；同技能按键但实际高速落地仍原伤。量化代价是Dheight=1时任何高于300的冲击都仍取整为1伤，例如301与779同为1，低落差减伤不是连续血量变化。以上为独立公式预期，不是运行结果。

## 7. 默认模块与未来更换接入口

新增独立移动模块定义，具有稳定ModuleId、有限时推力、投影上限、阻力与制动参数；先固定装配标准模块。普通重力／跳跃和着陆判定属于角色／地形规则，不让未来随便换喷嘴就同时改全世界重力。

加载／装配前完整校验有限数、正时长、正加速度、合法上限与制动／阻力范围，提交不可变快照；非法数据不部分修改已安装状态。模块Resource运行中被编辑不自动热改进行中的物理模型。

显式未来装配入口仅在角色存活、非暂停、真实站稳、非燃烧、无爪Aim／Travel／附着接管时允许。站稳定义为连续两个已完成物理tick有有效floor支撑且相对支撑切向速率小于1px/s、无普通跳或Shift待提交；移动平台可站稳，单个IsOnFloor布尔值不够。成功原子替换不可变配置并递增配置epoch，不改当前位置、实际速度、HP、检查点、碎片或使用预算；旧事件不能作用于新epoch。拒绝时保留旧模块及状态。空中／燃烧中更换拒绝，不让换装恢复使用次数。首版可用两个测试模块证明接口，不制作拾取物、背包UI或所有权保存。
