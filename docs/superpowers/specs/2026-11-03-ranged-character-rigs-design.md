# 四类远程身体、动作与美术接入口 · v214

细化原V05/V09，不缩减完整十一项。用户要求丰富敌人及可替换美术，当前四保存场景仍共用身体。只改善枪的方案不能满足该目标；付费生成/视觉看板超出当前仅无窗口授权。本次采用已有Godot C#程序分件作为可替换承载，正式族系素材、正常速度审美与玩家验收仍OPEN。具体轮廓/比例/节奏为开发决定，不冒认为用户批准稿。

## 设计与取舍

- 采用完整四角色轮廓+刚性双段四肢+真实攻击驱动承重/后坐/恢复；拒绝只换色/枪，也不先购买Spine或调用付费API。
- 散弹宽肩锅炉、连发窄身弹链、导弹低重心背筒、激光细长棱镜头。形体先在原68高/半径25胶囊附近组织，枪原装饰外伸保留；不是扩大真实受击范围。
- 新纯值`RangedCharacterRig`产生姿态，不分配原生Resource；实际Draw消费同一姿态/分件几何。两臂18+18、腿13+13固定段长，脚底localY34；肩肘腕/髋膝踝参与蓄力与开火，脚不随整个身体缩放。
- 基于有效真实时间平滑brace/aim/collapse，唯一发射区间施加临界阻尼后坐冲量；重复/重叠事件不重启。死亡/眩晕/撤爪/离树清攻击瞬态；检查点显式reset允许AttackId重启，不能用普通Idle悄悄清身份。
- 保留八个借用`Texture2D`插槽Torso/Head/UpperArm/Forearm/Thigh/Shin/Foot/Weapon。每件在文档画布内等比适配，刚性关节旋转/平移，不做全图伸缩；默认程序轮廓仍可用。资源由场景/调用方所有，表现器不Dispose借用纹理。
- `IRangedWeaponVisual2D : IEntityVisual2D`承担帧/取消/检查点重置，替换场景不需要改AI。四原保存场景默认类型/路径保持兼容，不承诺运行时热换节点。
- 瞄准世界向量转换为绘制节点局部方向；不改变权威Muzzle、伤害方向、预警或危险叶。图像枪口不作为碰撞几何。
