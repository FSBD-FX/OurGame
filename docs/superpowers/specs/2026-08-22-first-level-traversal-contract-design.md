# 《无名钟楼》第一关移动能力与关卡可达性设计

**日期：** 2026-08-22
**状态：** 已获用户批准；实施计划已完成，待顺序执行
**项目：** `E:\OurGame\Knight`
**适用范围：** 序章第一关六个房间、玩家跳跃与空中冲刺、机械丝辅助位移、首关移动引导与自动可达性验证
**上位规格：** `docs/superpowers/specs/2026-08-21-combat-readability-presentation-design.md`

## 1. 背景

真人试玩中出现了类似“二段跳”的组合操作：在空中同时使用 `W`、`Shift`、`K`、`Space`，再按一次 `Shift`，角色似乎获得了第二次向上位移。玩家已无法稳定复述按键顺序，但确认第一关某个节点看起来必须依赖这类组合才能通过。

当前代码没有二段跳能力。正式移动能力是：

- 地面或土狼时间内的一次跳跃；
- 每次腾空可消费一次方向空中冲刺；
- 机械丝命中锚点后施加一次离散牵引速度；
- 下劈命中后的反弹只属于战斗命中结果，不是通用二段跳。

`W + Shift` 会产生向上的空中冲刺，`K` 可能继续叠加机械丝牵引，因此组合后的视觉和高度会像二段跳。第二次 `Shift` 在真实落地前必须被拒绝；若被接受，属于空中冲刺错误刷新或碰撞状态误判。

上层摆锤房也存在真实的能力契约不透明：入口平台到第一摆台约需上升 124 px，而默认单跳理论高度约为 94 px；场景放置了 `AnchorLow`，本意是让该段成为机械丝教学路线。当前机械丝是短促牵引而非持续摆荡，若锚点、发射位置、落点或提示不够明确，玩家只能靠同时叠加跳跃、空中冲刺和机械丝试错。

## 2. 已批准结论

1. 序章第一关不增加二段跳。
2. 保留每次腾空一次方向空中冲刺；这是独立能力，不得被机械丝、攻击、暂停、房间切换或短暂碰撞错误返还。
3. 机械丝保持本轮既定的离散牵引，不在本设计中升级为弹性悬挂或连续摆荡。
4. 第一关每个必经移动段必须满足以下二者之一：
   - 可由单跳稳定通过；
   - 明确标记为辅助移动段，并在稳定起跳区域内提供可见、可锁定、可命中的机械锚点或同类辅助装置。
5. 空中冲刺可以提供容错、捷径或进阶表现；在完成首关教学前，不得成为没有提示的必需输入。

## 3. 能力权威与输入规则

### 3.1 跳跃

- `Space` 只在地面、有效土狼时间或有效落地缓冲中启动跳跃。
- 空中按下或持续按住 `Space` 不得新增向上冲量。
- 跳跃缓冲只可在真实落地时消费一次；不得由机械丝、冲刺结束、攻击或房间恢复伪造落地。
- 跳跃松键仍可截短上升速度，保持现有可变跳高。

### 3.2 空中冲刺

- 地面冲刺不消耗下一次腾空的空中冲刺。
- 离地后第一次 `Shift` 可按当前瞄准方向启动一次冲刺；`W + Shift` 是合法的向上空中冲刺。
- 从本次离地到下一次权威落地之间，后续所有 `Shift` 按下都必须被拒绝。
- 权威落地必须来自角色碰撞体的有效地面接触。墙面、天花板、平台侧边、机械丝命中、敌人接触、攻击反弹、暂停恢复、检查点恢复和房间切换都不得单独返还空中冲刺。
- 空中冲刺被拒绝时可以提供轻量 UI/音效反馈，但不得改变速度或动画成一次成功冲刺。

### 3.3 机械丝与组合输入

- 机械丝命中锚点可以替换或叠加当前速度，但不能修改跳跃次数或返还空中冲刺。
- 同一腾空周期内允许按任意顺序组合 `Space`、方向键、`Shift` 与 `K`；能力消费结果必须由状态决定，而不是由按键同时到达的顺序决定。
- 必测组合至少包括：
  - `Space → W+Shift → K → Shift`；
  - `Space+W+Shift+K` 同帧输入后再次 `Shift`；
  - `Space → K → Shift → Shift`；
  - 冲刺过程中机械丝命中、机械丝作用过程中再按冲刺；
  - 空中暂停并恢复、跨房间、受击、下劈反弹后再按冲刺。
- 除非期间发生真实权威落地，上述流程最多产生一次空中冲刺和一次地面/土狼跳跃。

## 4. 第一关关卡可达性合同

### 4.1 路段分类

每个必经移动段在 builder 与测试中标记为以下一种：

- **单跳段：** 不需要冲刺或机械丝；使用默认正式参数、从稳定站立位置起跳即可抵达。
- **辅助段：** 明确依赖机械锚点或其他可见辅助装置；起跳区、辅助目标和安全落点构成一条完整合同。
- **可选进阶段：** 可使用空中冲刺或更紧的操作获得捷径、隐藏内容或更快路线，但失败不会阻塞主线。

不得存在“未标记但实际需要跳跃 + 空中冲刺 + 机械丝同时成功”的必经段。

### 4.2 单跳段标准

- 自动验证使用正式 `PlayerTuning`、真实碰撞体和真实物理帧，不使用传送或直接写速度。
- 主线普通单跳应保留可感知容错，不以理论极限作为唯一成功点；目标是从标记起跳区内不少于中间 60% 的位置可完成。
- 可以保留接近极限的可选跳跃，但必须是非必经路线，并由落点轮廓和失败后的安全回收表达风险。
- 如果平台间距超出单跳合同，应调整平台位置/尺寸，或把该段改为有完整辅助合同的辅助段。

### 4.3 机械丝辅助段标准

- 起跳区内必须能看到或由首关指导明确指出目标锚点。
- 锚点必须在正式 Tap/Hold 范围、角度和视线合同内；方向提示与真实 `ThreadTarget2D` 位置一致。
- 使用一次机械丝后，正式 `PlayerPullSpeed` 必须让角色进入安全落点可达包络；不得要求同帧再叠加一个未教学的向上冲刺才能到达。
- 失败反馈要区分无目标、遮挡、冷却与目标丢失；玩家必须知道失败原因。
- 上层摆锤房的 `EntryFloor → LowerSwing`、`LowerSwing → MidSwing`、`MidSwing → HighSwing/MechanismLanding` 将逐段重新验证。原本不透明的第一段必须成为清楚的锚点教学，而不是隐藏组合键考试。

### 4.4 空中冲刺教学和用途

- 在空中冲刺首次可能有价值之前，第一关只显示一次轻量提示：方向键 + `Shift` 进行方向冲刺；已消费时给出简短不可用反馈。
- 主线不依赖玩家猜出 `W + Shift`。
- 冲刺用于修正轨迹、挽救失误或进入可选路线；若后续试玩表明某个主线段必须冲刺，则该段必须显式改为冲刺教学段并重新取得设计批准。

## 5. 场景与提示调整范围

本轮允许修改：

- 六房间 builder 中的平台位置、尺寸、锚点位置和对应生成场景；
- 第一关 guidance 的移动/冲刺/锚点文案、目标路径和一次性触发条件；
- 玩家空中冲刺消费状态、输入反馈和必要的只读诊断状态；
- 自动 route probe、真实 InputMap 组合测试、结构测试与 smoke；
- README 的正式能力说明、路线验收状态和资产接口表。

本轮不包含：

- 二段跳；
- 机械丝弹性悬挂、持续摆荡或蜘蛛侠式切向动量系统；
- 新增蹦床、弹跳软糖等全新玩法实体；
- 付费生成美术；
- 为了让测试通过而提高全局跳跃速度、重力宽容或机械丝牵引到破坏其他房间的程度。

如果单跳和现有机械锚点无法在不破坏节奏的前提下覆盖某段，必须停下并向用户提出具体的新辅助装置设计，不能私自加入。

## 6. 验证设计

### 6.1 规则级 RED/GREEN

- 纯 `PlayerMotionModel` 测试复现用户组合，并证明第二次空中冲刺在落地前被拒绝。
- 真实 `PlayerInputReader → PlayerMotor → CharacterBody2D` 物理测试使用正式 InputMap 重放组合，不直接调用模型。
- 在墙、天花板、平台侧边、机械丝命中、下劈反弹、暂停和房间切换边界后重复第二次 `Shift`，均不得获得新的冲刺。
- 真实地面落地后下一次空中冲刺必须恢复，防止修复把正式能力永久锁死。
- Mutation：临时在机械丝作用或任意碰撞后返还空中冲刺，命名断言必须失败。

### 6.2 路线级验证

- 为六个正式房间维护必经路段清单及其分类。
- 单跳段由真实物理 route probe 从多个起跳点执行，记录成功落点，不接受直接写坐标。
- 辅助段由真实 InputMap 使用一次机械丝完成；不得附带空中冲刺输入。
- 可选进阶段单独验证失败不会阻塞主线。
- 对上层摆锤房保存逐段命名证据，明确每段使用了 Jump、Thread 或 Dash 中的哪些能力。

### 6.3 交付门禁

- `.NET` 构建为 0 警告、0 错误。
- `RunPrototypeTests`、`RunPrologueTests` 和 `verify-prologue.ps1` 全绿。
- 首关 critical-path smoke 使用合法输入完成全部必经段，并输出每段能力消费标记。
- 生成 1280×720、60 FPS 的全流程证明录像；逐帧检查空中冲刺消费反馈、机械丝辅助段和失败清场。
- 最终由真人以正常速度完成一次第一关路线，记录是否仍出现“必须靠未知组合键”“疑似二段跳”或“锚点牵引不足”。任一问题复现都不算完成。

## 7. 完成条件

本设计完成时必须同时成立：

1. 序章没有二段跳，代码、UI、引导和 README 对能力说明一致。
2. 每次腾空最多一次方向空中冲刺，用户报告的组合输入和所有已知刷新边界均有真实回归测试。
3. 第一关所有必经移动段都被明确分类并由正式物理输入验证。
4. 普通必经段可单跳通过；超出单跳能力的必经段拥有明确、可靠、单次即可完成的辅助锚点合同。
5. 上层摆锤房不再要求未教学的多键叠加才能通过。
6. 全门禁、60 FPS 证明录像和正常速度真人试玩均通过。
