# 地面向上挥刃方向修补 · v325

服务原V03/V04/R-C“各向攻击有清楚动作”的已批准范围。当前实际命中盒Up=(0,-42)，Timeline也发布Up，但GroundAttack上臂／武器四期及内部腕轨迹不区分Up。须先原生证明，不能据静态同角度就宣布看见坏画面。

采用现有十槽、固定24+24双臂、原武器和双握点，在既有GroundAttack分支内为Up定义上举发力／经过／收势。不是旋转整个角色或命中盒，不改腿／碰撞／物理／时钟／伤害／能量，不新增第二动画时钟，不换PNG或买Spine。横斩、空中和下劈路径不改。具体姿态数值是开发样段，正常速度／审美另验；不代表A身份图或最终总装批准。

选择依据：沿实际phase/elapsed改关节，能纠正攻击方向与挥刃不一致；只转特效不能纠正腕肘，整rig旋转会破坏落脚和附件。向上挥刃需在相同地面／朝向／时刻相对横斩实际抬腕至少6单位、刃轴上转至少.4rad；这是检测“同一个横斩”的宽松程序门，不是优雅度评分。30/60/120Hz、两朝向、原双握点与腿不变、无缩放和原回稳都要保留。
