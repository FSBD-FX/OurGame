# G04 · 首次短喷教学接线

来源：原十一项 G04/G05、已批准纯键盘短喷/反向制动和 ECHO 固定提示要求。现有普通攻击说明包含短喷字样，但没有独立的机会/真实成功学习状态。本设计是开发侧对既有要求的具体实现，不是用户新批准的动作/物理方案。

- 目标：入口接地且未在攻击/持盾/抓取时提供一次短喷/反向制动提示；必要的首次机械爪教学、现有组合机关、近战、激光等提示优先。沿用固定无框阅读区，初始短喷卡零目标；爪教学结束后补短喷时，保留原EntranceExit路线标记及下降入口说明，不增加世界标记或泄露秘密。双语与实时改键。
- 成功：仅观察当前正式会话、当前 Player/Motor 的真实短喷 Started 记录。完整 owner/lifecycle/configuration 身份和有界游标有效才认领；按键、拒绝、旧会话/旧生命周期/断档 journal 不构成成功。
- 生命周期：第一次真实成功后，当前会话不再显示；指导关闭仍观察成功；已学会跨普通死亡/暂停/换区保留。新会话或换 Player/Motor 重置，并建立最新游标基线。提示不更改原 Completion Objective 或存档协议。
- 非目标：不改运动/战斗/地图/次数/能量；不宣称惯性、完整动作或正式首关已验收；不打开窗口、操作系统键鼠、使用真实存档、付费或创建自动化。
- 方案比较：固定加入攻击长说明不能识别首次成功；用计数差会受死亡清零影响；选择复用现有只读 Started journal，避免增加运动积分中同步回调和第二套事件历史。
- 验证：生产保存场景+内部实际按键验证机会卡、危险优先、暂停、拒绝、真实成功、重置、新局旧记录拒绝及改键/双语。布置到原支撑属于隔离夹具，不算正常走通路线或画面认可；正常速度美感与手感继续待验。

执行依据：用户已要求对既有十一项直接持续完成，仅关键信息缺失时询问；故不为本接线重复请求方案批准。真实连续显示仍须另外取得当次许可。
