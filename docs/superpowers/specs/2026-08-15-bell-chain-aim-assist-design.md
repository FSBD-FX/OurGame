# 第一关钟链机关近距离瞄准辅助设计

- 日期：2026-08-15
- 状态：已实施并通过自动验证；修复后真人 10–15 分钟首通验收待完成
- 项目：`E:\OurGame\Knight`
- 适用场景：序章第一关 Bell-Chain Convergence 的钟链机关

## 1. 问题与目标

真人试玩已经能够到达钟链机关，并能看见近处的金色菱形目标，但在没有持续按住朝向目标的方向键时，仅按 `K` 没有机械丝、命中或失败反馈。当前机械丝目标选择要求非零瞄准方向，并受全局 30° 锥角限制；因此玩家在已经靠近并识别正确目标后，仍可能因为方向输入为空或略有偏差而无声失败。

本次修改只解决第一关钟链机关的这一个输入摩擦点：玩家靠近金色菱形后，即使没有方向输入或方向略有偏差，按 `K` 也能通过真实机械丝流程牵动机关。普通锚点、敌人、Boss 锁链及后续关卡继续使用现有精确方向瞄准规则。

## 2. 已选方案

采用“目标级、默认关闭的近距离瞄准辅助”。

- `ThreadTarget2D` 暴露 `FallbackAimAssistRange`，默认值为 `0`，表示禁用。
- 只有第一关钟链机关的金色菱形目标设置该值，初始值为 `260px`。
- 机械丝始终先执行现有方向、锥角和距离选择。
- 只有正常选择没有命中目标时，才检查开启了近距离辅助的候选目标。
- 辅助候选仍必须在全局机械丝射程内、在自身辅助范围内，并通过真实视线遮挡检查。
- 选中后继续调用现有拉动接口、冷却、事件和表现，不直接打开机关或修改进度。

没有选择以下替代方案：

- 只增加提示文字：不能解决玩家已经看见目标、按下正确能力键却无响应的问题。
- 扩大全局锥角或射程：会同时降低敌人、锚点和 Boss 锁链的瞄准要求，改变整个能力的手感。
- 无条件吸附最近目标：会让 `K` 变成通用自动选择键，产生误命中和隐藏规则。

## 3. 玩家交互边界

### 3.1 成功路径

玩家位于钟链金色菱形目标 `260px` 内且视线无遮挡时：

1. 朝目标精确瞄准并按 `K`：使用原有正常选择。
2. 不按方向并按 `K`：正常选择为空，使用机关近距离辅助。
3. 方向略有偏差并按 `K`：若正常选择没有选中其他合法目标，使用机关近距离辅助。
4. 选中后显示现有机械丝线与命中反馈，调用真实 `ThreadTarget2D.ApplyPull`，由机关自身规则开启捷径。

### 3.2 拒绝路径

以下情况不得触发辅助：

- 玩家与目标距离超过 `260px`。
- 玩家与目标之间存在世界碰撞遮挡。
- 目标未启用辅助，包含普通锚点、轻敌、重敌和 Boss 锁链。
- 机械丝能力正在冷却或处于现有规则禁止使用的状态。
- 目标已经失效、离开 SceneTree 或不再可交互。

若正常方向选择已经选中合法目标，该目标始终优先，辅助不得抢占。

## 4. 组件与数据流

### 4.1 目标配置

`ThreadTarget2D` 增加导出浮点属性 `FallbackAimAssistRange`：

- `0` 或更小：辅助关闭；运行时按关闭处理。
- 大于 `0`：允许在该半径内参与兜底选择。
- 实际有效距离不得超过全局机械丝射程，即使用两者较小值。

第一关 `BellChainMechanism` 构建器把金色菱形目标配置为 `260`。其他现有目标不设置该属性，因此保持默认关闭。该配置是稳定的后续调参窗口，但本次不新增全局辅助开关或通用自动瞄准系统。

### 4.2 候选数据

运行时从 `ThreadTarget2D` 构造的目标候选携带辅助范围。纯选择模型不读取场景树或资源路径，只接收候选的距离、方向、视线结果、稳定标识和目标级辅助范围。

### 4.3 选择顺序

一次 `K` 输入按以下顺序处理：

1. 使用现有全局射程、30° 锥角、瞄准方向和视线规则寻找正常目标。
2. 找到正常目标后立即返回，不执行辅助选择。
3. 正常目标为空时，从辅助范围大于 `0` 的候选中筛选：目标有效、视线无遮挡、距离不超过全局射程与目标辅助范围的较小值。
4. 若有多个辅助候选，先选距离最近者；距离相同时用稳定目标标识排序，保证固定物理输入下结果确定。
5. 没有合法候选时维持现有失败行为，不消耗冷却、不伪造命中、不推进关卡。

辅助距离使用玩家机械丝发射原点到目标交互点的世界空间直线距离。进入兜底阶段后不再检查输入方向夹角；这是有意设计，使无方向、轻微偏向乃至错误方向都不会阻止已经贴近该专用机关的玩家。由于只有这个机关显式开启辅助、正常目标始终优先，错误方向不会让普通目标获得自动吸附。

### 4.4 命中与表现

辅助只改变“选择了哪个合法目标”，不另建命中路径。成功后仍由现有机械丝能力负责：

- 发出正常的发射与命中事件。
- 显示同一条机械丝表现。
- 应用同一冷却与输入锁定规则。
- 调用目标的真实拉动接口。
- 由钟链机关控制捷径、永久进度和后续指导目标切换。

因此后续替换机械丝、机关和目标标记美术时，不需要识别这次命中来自正常瞄准还是辅助瞄准。

## 5. 第一关指导文字

钟链机关步骤改为：

`靠近金色菱形，按 K 牵动机关；方向键可精确瞄准。`

该文字只属于序章第一关指导系统。它说明最小可行操作，同时保留方向键精确瞄准的进阶信息。其他关卡不会自动挂载这一提示或近距离辅助配置。

本次不增加新的动态失败弹窗、失败原因枚举或遥测字段；真实无声失败由辅助直接消除，超距和遮挡继续由空间关系表达，避免扩大系统范围。

## 6. 错误处理与兼容性

- 非法的负辅助范围按关闭处理，并由构建/结构测试阻止第一关场景写入非法值。
- 辅助范围大于全局射程时不得突破全局射程。
- 目标缺失或已释放时安全跳过，不缓存陈旧 Node 引用。
- 视线查询失败或被世界层遮挡时按不可选处理。
- 场景中不存在开启辅助的目标时，模型行为必须与修改前一致。
- 机关命中后仍必须由现有进度与房间控制器完成捷径开启；辅助层不得直接访问 `PrologueProgress`。

## 7. 测试与可见验收

实现与自动验收已完成：目标级 `260px` 兜底、真实视线/射程边界、普通与 Boss 目标保持精确瞄准、第一关中性 `K` 关键路径，以及引导菱形对齐真实 `ThreadTarget`，均已由单元/集成测试、完整序章门禁和修复后确定性录像验证。真人节奏验收仍遵循 7.4 的独立证据边界。

### 7.1 纯模型测试

- 无方向输入时，`260px` 内且开启辅助的候选被选中。
- 方向略偏且正常选择为空时，合法辅助候选被选中。
- 超过辅助距离、超过全局射程或视线被挡时不选中。
- 辅助范围为 `0` 的普通目标不参与兜底。
- 存在正常方向目标时，正常目标优先于辅助目标。
- 多个辅助候选按距离和稳定标识确定性选择。

### 7.2 场景与集成测试

- 生成的第一关钟链目标明确配置 `FallbackAimAssistRange = 260`。
- 其他代表性目标和 Boss 锁链保持 `0`。
- 在真实钟链房间中，把玩家置于近距离、不给方向输入、通过真实 InputMap 按下 `K`，验证机械丝命中、机关开启和指导立即改指 Boss 出口。
- 在辅助范围外或加入世界遮挡后，同样输入不得开启机关。
- 现有锚点、敌人拉动和 Boss 锁链集成流程继续通过。

### 7.3 回归证明

- 实现后做至少一次变异验证：把钟链辅助范围改回 `0` 或移除兜底选择，集成测试必须失败。
