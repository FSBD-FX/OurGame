# v270 · 放大界面时仍能读完键位并返回

G05 的高 UI 缩放在正常标题操作说明页实证。保持实际 1280×720 输出、全局 150% 和用户选定语言不变；标题与固定返回按钮完整在屏内，保留正文的 18/16pt 原字号，键盘能抵达所有行和返回。正常空间保留原页面结构与字体，不更改设置页、暂停页、按键绑定、玩法、颜色或资产风格。

开发判断：缩小整张面板会抵消用户选择的放大；整页滚动会让返回随内容出屏。采用正文区滚动、标题/返回固定，只有溢出才显示滚动提示。方向键作小步移动，PageUp/PageDown 翻页，保持现有 Back 初始焦点，Enter 返回标题；重新打开复位到开头。该决定属于已要求直接推进的 G05 可用性修复，不冒认新的美术批准。
