# 序章视觉品质要求与现有素材状态

状态：制作与验收尚未完成。此文将用户2026年9月20日的画面品质要求，以及此前提供的《空洞骑士式2D游戏美术资产完整方案_含Godot.docx》，落实到当前机械峡谷神殿序章。它不是成品美术验收报告。

## 制作方向

采用原创的机械遗落神殿视觉语言：轮廓明确、材质与光照统一，远中近景有层次，角色与攻击信息清楚。参考文档描述的是手绘二维作品的生产方法，不提供原游戏素材，也不意味着照搬其角色、建筑或UI。

画面可以幽暗，但玩家、敌人前摇、伤害主形、落脚点和可抓地形必须优先可见。环境亮点、雾、碎屑和前景不能与它们争夺注意力。避免密集噪点、明显重复、拉伸纹理、机械僵硬的动作与通用科技面板。

## 必须在游戏中检查的项目

| 范围 | 完成判断 |
| --- | --- |
| 场景 | 深渊、营地、机械区、上层回廊、神殿有不同构图、材料与地标；镜头运动时层次自然，没有接缝、露空或装饰遮住路线。背景差异不能冒充不同玩法。 |
| 角色与敌人 | 在实际游戏尺寸下看得懂朝向、起手、命中和收招；脚底、手部挂点、武器和悬浮灯稳定，翻转正确，披风运动自然。分部件代码存在不等于动作质量通过。 |
| 机械爪与护盾 | 发射、命中、牵引、松脱、助推、格挡与过热有明确可辨的动作和反馈；不可抓表面与可抓表面不会混淆。 |
| 战斗与机关 | 前摇先于伤害出现；伤害、闪光、音效与受击节奏一致。状态变化和危险范围清楚，粒子不遮住伤害主形。 |
| UI | 字体、字号、边距、图标、装饰与世界风格统一；Q/E模式、键鼠提示、气力、热量和道具槽清楚。菜单动效短而响应及时，不拖慢操作。 |
| 分层与替换 | 背景、中景、玩法可读层、前景与特效可独立调整；替换美术或关闭装饰不能改变碰撞、抓取材料、机关、触发与存档行为。 |
| 技术品质 | 透明边缘干净，缩放不糊、不变形；材质状态不错误影响其他实例；特效会清理。实测正常窗口帧表现，不能拿无渲染测试代替性能和观感。 |
| 成果证据 | 对照代表场景改造前后，审阅实际运动录像、UI状态和完整游玩；记录问题与缺失素材，再作完成判断。 |
