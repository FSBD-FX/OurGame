# v269 · 只让同一次游玩中的已领取补给跨标题保存

前轮 v268 为实质推进（中英操作说明同步已实作，最终四专项通过），但完整前段发现了 v266 的存档回归。本轮推进 P06/P07/Q05，不改变完整序章范围和批准的验收门。

## 事实与修复

- 补给真实身体接触后先登记领取，回血同步通知可以切回标题。v266 拦截通用 Title/Intro 保存是正确的，但漏掉了此时仍属于原游玩的领取；原生证据显示内存已消耗、隔离存档仍无记录。
- 领取开始时保存关卡、已提交 Save 引用、实际存档槽、发现 ID 和进入游戏代数；结束前仍须是同一入口、有效关卡及真实已领取发现。任何被接受的新游戏或继续都撤销旧领取，包含随后因写入失败退回标题的启动。退出、失效节点、不同槽也不能借此写入。
- 仅这个拥有者可以在标题完成同局快照，保留已提交 Save 的对象身份和检查点。仍旧在 Healed 之后发出一次原有 discovery 通知，通知前写入已经完成；通用 Title/Intro 不能由同名字符串绕开，也不重复写入。普通 Playing 路径保留原有顺序。
- 可用性变化只同步菜单缓存和 Continue 状态，不重置当前标题页面、焦点或迁移选择。
