专项用实际标题启动游戏，等进入 `Playing`，用 Godot 内部 Escape 暂停；在中英文、100% 与 150% 四组中检查内容与按钮边界、Tab／Shift+Tab、Enter 打开操作说明和恢复、暂停期间采样停止以及恢复时仍是同一角色。真实锁住 Windows 隔离档，验证退出显示保存失败、Retry 取得焦点，Escape 先关弹窗不恢复，再按才恢复，存档字节未改。不代签运行时调整缩放、重新挂载、样板的失败弹窗、其他屏幕比例或实际可见效果。
