# v227 · 反向和再次起步的摆脚交接

本次修改游戏实际使用的 `PlayerGroundGait.MoveSwing`，没有重调移动或物理，也没有新增资产。前一轮 v226 是验路支撑修正；本轮是表现层修正，不能合并成全关同版通过。

## 事实与修正

反向或收脚时重新起步会从当前已经抬起的脚底重启摆动。旧算法把尚未落下的高度保留在插值中，再叠加一个完整的 8px 摆脚弧。平地 `0→18→10` 的实际 Godot 模型反例中，地面 Y=36，足底从 Y=28 到 23.331354，即抬高约 12.67px。

保留原水平位移、支撑脚、插值、制动压低量和收脚逻辑。以起点相对落点沿支撑面法线的高度扣减新弧预算；已有高度继续随原插值回落，不硬截顶。没有接管输入、Motor、碰撞、跳数或存档。
